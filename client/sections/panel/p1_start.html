Bienvenido a MineControlPanel

MineControlPanel es el panel de administración de nuestro servidor de Minecraft. Desde aquí podrás consultar información del servidor, visualizar el mapa del mundo en tiempo real y gestionar distintos aspectos del servidor.

Este proyecto ha sido desarrollado para facilitar la administración del servidor mediante una interfaz web simple e intuitiva.

  • Ver la ip del servidor de Minecraft en local
  • Administrar la terminal del servidor
  • Consultar jugadores conectados
  • Administrar configuraciones del servidor
