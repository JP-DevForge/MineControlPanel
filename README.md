# MineControlPanel

MineControlPanel es un panel de administración web para servidores Minecraft Vanilla, desarrollado en Node.js. Permite gestionar múltiples servidores desde una única interfaz moderna, tanto en Linux como en Windows.


## Características

- Crear servidores Vanilla automáticamente.
- Añadir servidores existentes mediante su archivo `.jar`.
- Iniciar, detener y reiniciar servidores.
- Monitorización en tiempo real.
- Gestión multi-servidor.
- Detección automática de estado.


## Requisitos

### Linux

- Node.js 20+
- Java 21+
- pnpm

### Windows

- Node.js 20+
- Java 21+
- pnpm
